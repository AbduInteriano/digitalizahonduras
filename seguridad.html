Medidas de seguridad del sitio

Resumen de protecciones aplicadas para publicación en línea.

Qué ya está implementado

  • Cabeceras HTTP de seguridad (.htaccess y _headers)
  • Content-Security-Policy para limitar scripts y frames
  • Anti-clickjacking (X-Frame-Options / frame-ancestors)
  • Formulario con honeypot, tiempo mínimo y cooldown
  • Sanitización de entradas y sin innerHTML con datos del usuario
  • Scripts externos con defer
  • Sin listado de directorios y bloqueo de archivos sensibles

Recomendado en el hosting

  • HTTPS obligatorio (certificado SSL)
  • WAF / Cloudflare delante del dominio
  • Backups automáticos del hosting
  • Actualizar el número real de WhatsApp antes de publicar
  • No subir .env, claves ni paneles admin a este repo estático
